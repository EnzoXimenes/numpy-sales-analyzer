# 📊 NumPy Sales Analyzer

> Analisador de vendas desenvolvido em Python utilizando NumPy para aplicar conceitos de análise estatística e manipulação de dados.

## 🎯 Sobre o projeto

Este projeto foi desenvolvido como parte da minha jornada de aprendizado em **Python para Data Science e Inteligência Artificial**.

O objetivo é analisar os dados de vendas de diferentes lojas ao longo de uma semana e extrair informações relevantes para auxiliar na interpretação dos resultados.

## 🔎 Análises realizadas

O programa responde perguntas como:

* Qual loja apresentou o maior volume de vendas?
* Qual loja apresentou o menor volume de vendas?
* Qual foi a média de vendas de cada loja?
* Qual foi a média de vendas em cada dia?
* Qual loja apresentou maior consistência nas vendas?
* Qual foi o melhor dia de vendas?
* Qual foi o pior dia?
* Qual é o percentil 90 das vendas?
* Quantas vendas ficaram abaixo da média geral?

## 🧠 Conceitos praticados

Durante o desenvolvimento foram utilizados conceitos fundamentais do NumPy:

* Arrays multidimensionais
* `np.mean()`
* `np.std()`
* `np.sum()`
* `np.argmax()`
* `np.argmin()`
* `np.percentile()`
* Máscaras booleanas
* Indexação
* `axis=0`
* `axis=1`
* Análise estatística básica

## 📊 Dataset

O conjunto de dados representa as vendas de **5 lojas durante 7 dias**.

Cada linha representa uma loja e cada coluna representa um dia da semana.

```text
5 lojas × 7 dias
```

## 🚀 Tecnologias

* Python
* NumPy

## 📈 Resultados

O programa identifica, entre outros resultados:

* 🥇 Loja 3 como maior média de vendas
* 📉 Loja 4 como menor média de vendas
* 📊 Loja 4 como a mais consistente
* 🏆 Dia 6 como o melhor dia
* 📉 Dia 1 como o pior dia
* 🎯 Percentil 90 das vendas: 206
* 📊 Média geral: 139
